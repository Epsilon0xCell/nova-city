# Nova City: Build. Live. Survive.

Nova City is a closed source game. This public repository holds only the files the website needs to run, so anyone can play the game in a browser. The game source code, its history, and the development tools are private and are not published here.

## Play

Play the current build here: https://epsilon0xcell.github.io/nova-city/

## Downloads

Packaged builds of the game are published on the Releases page of this repository: https://github.com/Epsilon0xCell/nova-city/releases
